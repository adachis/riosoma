# Trusted Types boundaries

The server enforces `require-trusted-types-for 'script'`.  Existing CSP source lists remain unchanged.  Only `rio-sanitizer`, `rio-html`, and `rio-script-url` are allowed.  `trusted-types.ts` creates the two HTML policies, and `trusted-script-url.ts` creates `rio-script-url` without loading the sanitizer.  No default policy is installed.  The window caches each policy under its own stable symbol so module reloads cannot recreate their names.

No HTML sanitizer existed in the application.  An inert parse5 pass removes event-handler attributes, nested srcdoc attributes, and inline styles before browser parsing, since Chromium reports CSP violations even in detached documents.  DOMPurify then sanitizes HTML before `rio-html` creates TrustedHTML.  Its private `rio-sanitizer` policy grants only DOMPurify access to its inert parser, and it rejects script URLs.  React and DOM declarations still require strings, so boundary casts preserve opaque Trusted Types objects without converting them back to strings.  Browsers without Trusted Types still receive sanitized HTML and validated script URLs.

| Browser sink or component                                                                 | Boundary                                                                                     |
| ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Clipboard HTML in `files/clipboard.ts` and `grid/clipboard/read.ts`                       | Sanitized TrustedHTML enters DOMParser                                                       |
| SVG artwork in `brand/entrance.ts`, inserted by `RiosomaLogo`                             | Sanitized TrustedHTML enters DOMParser and React                                             |
| Sparkline SVG in `colors/sparklines.ts` and `SparklineChart`                              | Sanitized TrustedHTML enters innerHTML and React                                             |
| Sandboxed site preview iframe srcdoc                                                      | Sanitized full-document TrustedHTML retains CSP metadata and stylesheet links                |
| Tiptap core DOMParser and optional style innerHTML                                        | The Vite dependency adapter supplies sanitized TrustedHTML                                   |
| ProseMirror clipboard innerHTML                                                           | The adapter removes its pass-through policy and uses the central sanitizer                   |
| MapLibre DOMParser for attribution and popup innerHTML                                    | The adapter sanitizes before MapLibre's own allowlist                                        |
| MapLibre worker constructors                                                              | The adapter supplies TrustedScriptURL for the shipped worker configured by `MapCanvas`       |
| ECharts tooltip and data-view innerHTML, SVG export, and ZRender clearing and XML parsing | The adapter supplies sanitized TrustedHTML                                                   |
| React Aria live-announcer clearing                                                        | Empty clears use replaceChildren, which cannot parse or execute HTML                         |
| React DOM HTML and generic attributes                                                     | HTML and iframe srcdoc are sanitized, script URLs are validated, and script text is rejected |
| Google Picker loader script src                                                           | TrustedScriptURL in `trusted-script-url.ts` allows only `https://apis.google.com/js/api.js`  |
| Service worker registration                                                               | TrustedScriptURL in `trusted-script-url.ts` allows `/sw.js`                                  |
| Service worker importScripts                                                              | Removed by inlining the shipped notification listener before the runtime                     |
| Import rows worker                                                                        | TrustedScriptURL in `trusted-script-url.ts` for Vite's emitted worker asset                  |
| PDF attachments and signature and print previews                                          | Browser-native new-tab or frame viewer, with no PDF.js DOM or worker sinks                   |

The production build runs `build/trusted-types-guard.ts` over the transformed JavaScript of every module selected by the bundler, including app code, dependencies, virtual modules, lazy chunks, and separate worker bundles.  It also checks emitted JavaScript assets, public scripts, and the assembled service worker after output plugins finish.  The adapter list determines which dependencies receive rewrites, and it grants no exemption from the guard.  New dependencies receive the same checks automatically.  A failure identifies the module, sink, and a short source snippet.

The guard checks innerHTML, outerHTML, insertAdjacentHTML, document.write and writeln, DOMParser.parseFromString, Range.createContextualFragment, srcdoc, script src and text, dynamic setAttribute calls, Worker and SharedWorker constructors, importScripts, eval, Function constructors, and string timers.  Empty-string HTML assignments receive the same check as every other assignment.  The adapter may replace an empty clear with replaceChildren or replaceWith, retaining the expression result while removing the HTML parser sink.  Policy helpers must be imported from the actual security module, and immutable local aliases preserve that provenance.  Compound HTML assignments fail because concatenation would discard the opaque type.

Some syntax has another meaning, such as a tokenizer's write method or a layout object's text property.  The guard proves simple non-script DOM constructions and function callbacks directly.  Additional construction proofs in `build/trusted-types-safe.ts` state the reason and lock the complete transformed module with a SHA-256 fingerprint.  A source change invalidates the proof, including dependency upgrades.  DOMPurify's private parser capability has such a proof, backed by the sanitizer tests.  There are no module-wide unchecked exemptions.

The adapter disables MapLibre's optional classic worker evaluation, PDFMake's obsolete document polyfills and dynamic code generators, and Zod's optional compiler.  Legacy global-object discovery uses globalThis directly.  React's parser-created script branch is disabled because the application does not render script elements.  Its HTML assignments and generic attribute dispatch use a small runtime boundary that delegates to the central policies after the sanitizer loads.  Sensitive values fail closed before initialization, so the parser stays out of the startup shell.  The guard permits boundary registration only from the policy module.  Timer callbacks that cannot be established statically pass through a function check, which rejects strings before scheduling and retains the original function and arguments.  The opaque custom-code frame has its own isolated CSP and does not execute code in the application document.

The remote Google Picker implementation is not shipped in this tree.  Its loader boundary is checked here, and live vendor behavior requires a configured integration.  No remote service is contacted by the regression suite.

The Chromium screen check captures every securitypolicyviolation from the beginning of each document, exercises rich HTML paste, and verifies service worker activation.  Unit tests run the actual sanitizer in JSDOM because Happy DOM does not implement its required DOM invariants.
