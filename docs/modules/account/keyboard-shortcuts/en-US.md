Open {{ui:shell.personalMenu}} and choose {{ui:shortcuts.title}} from any signed-in screen.  Groups name the context where each action applies.  The current screen's groups appear first, and the columns adapt to the available width.  Phones show one column.

Use {{ui:shortcuts.filter}} to find an action name or key combination.  Enter keeps you in the filter.  Keys use the device's Mac symbols or Windows names.  The same registry supplies shortcut handlers, command labels, and help references such as {{keys:palette.open}} and {{keys:settings.save}}.

In a grid, undo with {{keys:grid.undo}}, redo with {{keys:grid.redo}}, and select all cells with {{keys:grid.all}}.  Fill a selection down with {{keys:grid.fillDown}} or right with {{keys:grid.fillRight}}.  Find with {{keys:grid.find}} and replace with {{keys:grid.replace}}, including while editing a cell.  Replace uses a different Mac combination so it does not hide the app.

Use the close icon in the header or press Escape to close the panel.  Add `?shortcuts=1` to a signed-in page's address to open its shortcuts directly.  Add `?appearance=1` to open the quick appearance switch on that page.
