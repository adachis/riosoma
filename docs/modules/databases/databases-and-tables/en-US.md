A database holds related tables.  Each table is a list of records, like rows in a spreadsheet, and each field is a column that knows what kind of value it holds.

## Starting a database

From Home, choose {{ui:home.new}}, name the database, and pick a color.  It starts with one table that has a few fields and three empty records, ready to fill in or reshape.

## Tables

The sidebar lists the database's tables.  Choose {{ui:synced.add.menu}}, then {{ui:synced.add.blank}}, to make another.  Each table's menu renames or deletes it, and you can drag tables into the order you like.  A database always keeps at least one table.

## Records

Every row in a table is a record.  Add one with the last row of the grid, or with {{ui:grid.record.insertAbove}} and {{ui:grid.record.insertBelow}} from a row's menu.  To see all of a record's fields at once, expand it from the row's number or with Shift+Space.

Every table, view, and record has its own address.  Copy it from the address bar and anyone with access lands in the same place.
